# TC

This repository contains the code and analytical framework for the study:

Health system resilience reshapes tropical cyclone adaptation under climate change

# Overview

Tropical cyclones (TCs) are intensifying under climate change, yet whether repeated hazard exposure builds adaptive capacity or compounds health vulnerability has remained unresolved. This study provides an integrated hazard–resilience–health analytical framework to quantify TC-attributable hospitalization burdens, evaluate the role of health system resilience (HSR) in moderating TC-health impacts and enabling experience-based adaptation, and project future burdens under divergent climate, demographic, and HSR development pathways.
